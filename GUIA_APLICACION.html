1. Introducción general

Esta aplicación permite sincronizar incidencias desde Jira Cloud, almacenarlas en una base de datos local y analizarlas mediante IA.

Funcionalidades principales

  • Dashboard inicial.
  • Timeline de incidencias.
  • Alertas críticas.
  • Informes IA.
  • Gestión de usuarios.

Integraciones

  • Jira Cloud REST API.
  • OpenAI API.
  • Teams / Power Automate.
  • SMTP.
  • Twilio Voice API.

2. Arquitectura general

Flujo general

Jira Cloud
   ↓
Servicios PHP
   ↓
Base de datos MySQL/MariaDB
   ↓
Endpoints public/api
   ↓
Páginas PHP + JavaScript
   ↓
Usuario

Capas

  • public/*.php: páginas visuales.
  • public/api/*.php: endpoints HTTP.
  • app/services/*.php: lógica de negocio.
  • app/models/*.php: acceso a base de datos.
  • app/config/*.php: configuración.
  • app/helpers/*.php: autenticación y utilidades.

20. APIs externas utilizadas

Jira Cloud REST API

  • Buscar incidencias.
  • Editar incidencias.
  • Cambiar estado.
  • Obtener transiciones.
  • Crear/invitar usuarios.
  • Buscar accountId.

OpenAI API

https://api.openai.com/v1/chat/completions

Usada en informes de incidencias, informes 12H e informes de cierre.

Teams / Power Automate

TEAMS_WEBHOOK_URL

SMTP

Usado para alertas por email, confirmación de alta e invitación a Teams.

Twilio Voice API

https://api.twilio.com/2010-04-01/Accounts/{SID}/Calls.json
